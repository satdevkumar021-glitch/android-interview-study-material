💡 Study Science Tips
🔁
Spaced Repetition
Use the flip cards. Mark "Review" on anything you couldn't recall immediately. Revisit marked cards every 2 days. This is how long-term memory works.
🗣️
Teach Out Loud
Say the 30-sec answer out loud after reading each topic. If you can't explain it in 30 seconds without looking, you don't know it well enough yet.
✍️
Write Code From Scratch
Don't just read code — close the page and write the ViewModel, the Repository, the coroutine scope from memory. Muscle memory matters in coding rounds.
🎯
Quality Over Quantity
5 topics deeply understood beats 20 topics skimmed. Interviewers drill deeper. Know the "Why" behind every decision — not just the "What".
🔗
Connect the Dots
After each section, ask: "How does this connect to what I already know?" Architecture → ViewModel → StateFlow → Compose → collectAsStateWithLifecycle. The chain matters.
😴
Sleep is Studying
Memory consolidation happens during sleep. Don't pull all-nighters before interviews. Study hard, sleep well. 7–8 hours before interview day is non-negotiable.
📅 Interview Day Checklist
Night Before
Light Review Only
Go through your flash cards marked "known". Read your 5 STAR stories. No new topics. Sleep by 10pm.
Morning
Warm Up, Don't Cram
Read the Quick Revision sheets for 3 most likely topics (Coroutines, Compose, Architecture). Eat well. Exercise 20 min if possible.
During Interview
Think Out Loud Always
Never code in silence. Say: "My first thought is X but I'd also consider Y because..." Senior engineers are evaluated on reasoning, not just answers.
System Design Round
Clarify → Diagram → Trade-offs
Ask clarifying questions first. Draw ASCII diagram. Call out trade-offs explicitly. Mention failure handling. Show you've built this in production.
After Each Round
Reset Fast
Don't dwell on mistakes in previous rounds. Each round is independent. Interviewers don't share scores between rounds mid-loop.
