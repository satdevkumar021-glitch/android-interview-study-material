2. Reverse a String
1
"hello" → "olleh"
O(n) time · O(n) space
Approach 1: Kotlin stdlib (preferred in production)
fun reverseString(s: String): String = s.reversed()

// reversed() internally uses StringBuilder — O(n) time, O(n) space
println(reverseString("hello"))   // "olleh"
println(reverseString(""))        // ""    (edge case: empty string)
println(reverseString("a"))       // "a"   (edge case: single char)
Approach 2: Manual with StringBuilder (show you understand it)
fun reverseStringManual(s: String): String {
    val sb = StringBuilder()
    for (i in s.indices.reversed()) {
        sb.append(s[i])
    }
    return sb.toString()
}

// Why StringBuilder not String?
// String is immutable — "str" + char creates a new String each time → O(n²)
// StringBuilder is mutable — append is amortized O(1) → O(n) total
Approach 3: Two-pointer in-place (show algorithmic thinking)
fun reverseCharArray(chars: CharArray) {
    var left = 0; var right = chars.size - 1
    while (left < right) {
        val temp = chars[left]
        chars[left] = chars[right]
        chars[right] = temp
        left++; right--
    }
}
// O(n) time, O(1) space — modifies array in place

3. Palindrome Check
2
"racecar" → true, "hello" → false
O(n) time · O(1) space
Brute Force O(n) time, O(n) space
fun isPalindromeNaive(s: String): Boolean = s == s.reversed()
// Creates a new reversed string — O(n) extra space
Optimal: Two-pointer O(n) time, O(1) space
fun isPalindrome(s: String): Boolean {
    var left = 0; var right = s.length - 1
    while (left < right) {
        if (s[left] != s[right]) return false
        left++; right--
    }
    return true
}

println(isPalindrome("racecar"))  // true
println(isPalindrome("hello"))    // false
println(isPalindrome(""))         // true  (empty string is palindrome)
println(isPalindrome("a"))        // true  (single char)
Variation: Ignore case and non-alphanumeric
// "A man, a plan, a canal: Panama" → true
fun isPalindromeClean(s: String): Boolean {
    val cleaned = s.filter { it.isLetterOrDigit() }.lowercase()
    return isPalindrome(cleaned)
}

4. Anagram Check
3
"listen", "silent" → true
O(n) time · O(1) space (26 letters)
Brute Force O(n log n)
fun isAnagramNaive(s: String, t: String): Boolean =
    s.toSortedSet() == t.toSortedSet()
// Sorting: O(n log n) — works but not optimal
Optimal: HashMap frequency count O(n)
fun isAnagram(s: String, t: String): Boolean {
    if (s.length != t.length) return false  // fast early exit

    val freq = HashMap<Char, Int>()

    // Count chars in s (increment) and t (decrement)
    for (ch in s) freq[ch] = (freq[ch] ?: 0) + 1
    for (ch in t) freq[ch] = (freq[ch] ?: 0) - 1

    // All counts must be 0 for anagram
    return freq.values.all { it == 0 }
}

println(isAnagram("listen", "silent"))  // true
println(isAnagram("hello", "world"))    // false
println(isAnagram("ab", "a"))          // false (length differs)

// Kotlin idiomatic — sort chars and compare
fun isAnagramKotlin(s: String, t: String): Boolean =
    s.toCharArray().sorted() == t.toCharArray().sorted()

5. Find Duplicate Characters
4
"programming" → [g, r, m] (appear more than once)
O(n) time · O(k) space
fun findDuplicates(s: String): List<Char> {
    // Step 1: Count frequency of each char
    val freq = HashMap<Char, Int>()
    for (ch in s) freq[ch] = (freq[ch] ?: 0) + 1

    // Step 2: Filter chars that appear more than once
    return freq.filter { it.value > 1 }.keys.toList()
}

// Kotlin idiomatic one-liner:
fun findDuplicatesKt(s: String): List<Char> =
    s.groupingBy { it }.eachCount()
     .filter { it.value > 1 }
     .keys.toList()

println(findDuplicates("programming"))  // [r, g, m] (order may vary)
println(findDuplicates("abcde"))       // [] (no duplicates)
println(findDuplicates(""))           // []

// Character frequency map (useful helper function)
fun String.charFrequency(): Map<Char, Int> =
    groupingBy { it }.eachCount()

6. First Non-repeating Character
5
"leetcode" → 'l' (first char that appears exactly once)
O(n) time · O(k) space
Key insight: LinkedHashMap preserves insertion order
fun firstNonRepeating(s: String): Char? {
    // LinkedHashMap maintains insertion order — crucial for "first"
    val freq = LinkedHashMap<Char, Int>()
    for (ch in s) freq[ch] = (freq[ch] ?: 0) + 1

    // First entry with count == 1 (LinkedHashMap preserves insertion order)
    return freq.entries.firstOrNull { it.value == 1 }?.key
}

println(firstNonRepeating("leetcode"))  // 'l'
println(firstNonRepeating("aabb"))      // null (all repeat)
println(firstNonRepeating("a"))         // 'a'

// Alternative: two-pass approach (HashMap then scan original string)
fun firstNonRepeatingAlt(s: String): Char? {
    val freq = s.groupingBy { it }.eachCount()
    return s.firstOrNull { freq[it] == 1 }  // scan original order
}
// O(n) time, O(k) space where k = unique chars (max 26 for lowercase)
Why LinkedHashMap?
HashMap doesn't guarantee order. If you iterated HashMap.entries to find the first unique char, you'd get a random char, not the "first" one. LinkedHashMap maintains insertion order (the order chars first appeared in the string), so iterating entries gives you chars in their original appearance order.

9. Practice Questions
Why use StringBuilder instead of String concatenation when building a reversed string?
Easy▼
String is immutable — each concatenation ("str" + char) creates a new String object. Building a reversed string with + in a loop is O(n²) time and generates n temporary String objects. StringBuilder is mutable — append() adds to an internal buffer in amortized O(1) time. Total: O(n) time, O(n) space for the result. The Kotlin + operator on Strings compiles to StringBuilder internally for small operations, but explicit StringBuilder is clearer and guaranteed efficient.

How do you count the frequency of each character in a string in Kotlin idiomatically?
Easy▼
val freq: Map<Char, Int> = s.groupingBy { it }.eachCount(). This uses groupingBy to group characters by themselves (identity function), then eachCount() counts occurrences. Result: {"l":1, "e":3, "t":1, "c":1, "o":1, "d":1} for "leetcode". Manual alternative: s.forEach { freq[it] = (freq[it] ?: 0) + 1 } using getOrDefault(it, 0) + 1.
What is the difference between HashMap and LinkedHashMap for first-unique-character?
Medium▼
HashMap doesn't guarantee iteration order — iterating entries might return characters in any order. LinkedHashMap preserves insertion order — when you iterate entries, characters appear in the order they first appeared in the string. For first-non-repeating, if you iterate a HashMap and find a char with count 1, it might not be the FIRST such char in the original string. LinkedHashMap guarantees the first entry with count 1 is indeed the first non-repeating character.
How would you check if two strings are anagrams in O(n) time and O(1) space?
Medium▼
Use a fixed-size array of 26 for lowercase letters instead of a HashMap. val count = IntArray(26). For each char in s: count[ch - 'a']++. For each char in t: count[ch - 'a']--. Return count.all { it == 0 }. The array has size 26 (constant) regardless of input size → O(1) space. HashMap would also be O(k) where k ≤ 26 for lowercase letters, technically O(1), but the array version is more memory-efficient.
Write a function to reverse only the words in a sentence (words in reverse order).
Medium▼
fun reverseWords(s: String): String = s.trim().split("\\s+".toRegex()).reversed().joinToString(" "). Steps: trim() removes leading/trailing spaces, split on whitespace regex handles multiple spaces, reversed() reverses the list of words, joinToString(" ") joins with single space. " hello world " → "world hello". Alternative: s.split(" ").filter { it.isNotEmpty() }.reversed().joinToString(" ").
What is the time complexity of the two-pointer palindrome check vs reversed() comparison?
Easy▼
Both are O(n) time. The difference is space: reversed() creates a new String of length n → O(n) extra space. Two-pointer uses only two index variables → O(1) extra space. For an interview, mention both, show the two-pointer solution as the space-optimized answer. In production Kotlin, s == s.reversed() is perfectly fine and more readable.
How would you find if a string contains all unique characters without using extra data structures?
Hard▼
For lowercase ASCII only: use a bitmask (Long). For each char: val bit = 1L shl (ch - 'a'). If (mask and bit) != 0L, char seen before → not unique. Else: mask = mask or bit. O(n) time, O(1) space. No HashMap needed. For full Unicode: you can't avoid O(k) space; use HashSet. Brute force without extra space: compare every pair O(n²), or sort first O(n log n) then check adjacent chars O(n).
Write a Kotlin extension function that counts vowels in a string.
Easy▼
fun String.vowelCount(): Int = count { it.lowercaseChar() in "aeiou" }. Or: fun String.vowelCount() = filter { "aeiouAEIOU".contains(it) }.length. Using a Set for O(1) lookup: val vowels = setOf('a','e','i','o','u'); fun String.vowelCount() = count { it.lowercaseChar() in vowels }. Using contains on a String is O(k) where k=10 vowels, which is effectively O(1).
How do you find the length of the longest substring without repeating characters?
Hard▼
Sliding window with HashMap: track the last seen index of each character. fun lengthOfLongestSubstring(s: String): Int { val lastIndex = HashMap<Char, Int>(); var start = 0; var maxLen = 0; for ((i, ch) in s.withIndex()) { if (ch in lastIndex && lastIndex[ch]!! >= start) { start = lastIndex[ch]!! + 1 }; lastIndex[ch] = i; maxLen = maxOf(maxLen, i - start + 1) }; return maxLen }. "abcabcbb" → 3 ("abc"). O(n) time, O(k) space.
